2026-09-29 的阶段快照覆盖 10 次运行，其中 8 个阶段到达目标步数，2 次历史运行未完成。`Task5` 单任务专家已经完成；`Task1–5` 全局合并是另一阶段，在此阶段快照制作时尚未完成。它的最终准确率、遗忘率和最终图表只有核实完成后才补录；每份包的最新覆盖范围以根目录“先读我”和指南末尾结果篇为准。

资料包保留实验数据、原始指标、运行配置和实现源码。约 67 GB 的 `.ckpt` 模型检查点保存在原工作区，包内提供索引及已读取的检查点元数据，没有装入权重二进制。因此可以从包内数据复算统计、绘图和开展新的训练；直接恢复已有模型或重跑权重推理，需要使用索引指向的原始检查点。用于其他数据集的第三方示例数据、第三方展示图片、历史论文展示 notebook、Git 内部目录及 Python 环境二进制也未装入。

在新目录中准备 CIFAR-10 时，从解压后的根目录执行：

```bash
python3 docs/prepare_cifar10.py
```

脚本使用包内压缩数据准备 `data/cifar-10-batches-py/`，并为回放加载器准备 `data/cl/cifar-10-batches-py/`。同一文件优先用硬链接复用，已有相同数据会跳过。这个脚本不启动训练。

回放图像是 `float32` 的 `[N, 3, 32, 32]` 张量，值域 `[0, 1]`；标签为对应的类别编号。以下例子只在 CPU 上读取已有样本：

```python
from pathlib import Path
import torch

prefix = Path("data/cl/CL_CIFAR10_SUP_TASK1-4_SEED12_RERUN_T1_4")
images = torch.load(str(prefix) + "_imgs.pt", map_location="cpu", weights_only=True)
labels = torch.load(str(prefix) + "_labels.pt", map_location="cpu", weights_only=True)
print(images.shape, labels.shape)
print(labels.unique(return_counts=True))
```

已有 PNG/SVG 图不需要安装软件就能查看。重新生成阶段图表需要已配置的 JDCL 环境，以及绘图依赖：

```bash
conda activate jdcl
python -m pip install -r docs/requirements-analysis.txt
python analysis/completed_experiments_20260929/plot_results.py
```

绘图脚本读取包内 CSV/JSON 和回放张量，不需要模型检查点。`extract_results.py` 是原工作区使用的数据提取脚本；它会同时读取日志和检查点，完整重提取需要补齐原始权重。

解压后可以验证所有载荷文件：

```bash
python3 docs/verify_bundle.py
```

也可以直接验证 ZIP：

```bash
python3 docs/verify_bundle.py --archive /路径/资料包.zip
```

Task1–5 结束后，在原工作区补录最终数据，再重新打包：

```bash
conda activate jdcl
python docs/update_final_results.py
python3 docs/package_experiment_bundle.py
```

补录脚本会核对目标步数、日志结束消息及教师检查点来源；训练没结束时不会把临时值写成最终结果。打包脚本只纳入已经核实的最终结果，保留此前阶段快照，并生成新的压缩包及 SHA-256 校验文件。这两个命令不会启动训练。
